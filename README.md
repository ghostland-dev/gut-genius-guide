# SmartMealPlanner Medical

Personalised meal plans adapted to medical constraints.

## Features

- Authentication
- Nutrition dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/gut-genius-guide.git
cd gut-genius-guide
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
